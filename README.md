# 2D Platformer Prototype

Simple 2D platformer prototype built with **pygame**.

Loads tile maps, handles scrolling, collision,  
player movement and basic level transitions with audio and visual effects.

This was a school project where I started learning "music for videogames", while also going overboard  
and doing this in python.

python3 -m pip install -U pygame --user
